# language-translater-tol
🌐 Project Overview
The Language Translation Tool is a web-based application that allows users to:

Enter text in one language.

Select a source and target language.

Translate the text using an API (Google Translate or Microsoft Translator).

Display the translated text clearly on the screen.

Provide extra usability features like copy-to-clipboard and text-to-speech (TTS).

It combines a Flask backend with a simple HTML/CSS frontend, making it lightweight and easy to run locally.

📋 Key Features
User Interface (UI):  
Text input box, dropdowns for language selection, and buttons for translation, copy, and speech.

API Integration:  
Uses Microsoft Translator API for translation and Azure Speech Service for text-to-speech.

Output Display:  
Shows translated text and allows users to copy or listen to it.

Optional Enhancements:

Dynamic voice/language selection for speech output.

Error handling for failed translations.

Styling for a clean, user-friendly experience.

📝 Summary
This project is a complete translation assistant that not only converts text between languages but also speaks the translated text aloud. It’s practical for:

Students learning new languages.

Travelers needing quick translations.

Professionals working in multilingual environments.

By combining translation and speech, the tool bridges both written and spoken communication, making it more versatile than a basic translator.
